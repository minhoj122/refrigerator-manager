# 🧊 냉장고 식재료 유통기한 관리 및 레시피 추천 프로그램

실생활에서 식재료 유통기한을 놓쳐 버려지는 자원 손실을 줄이고, 남은 재료를 효율적으로 활용할 수 있도록 돕는 파이썬 텍스트 기반 관리 프로그램입니다.

## 📌 주요 기능
1. **식재료 등록**: 식재료 이름과 유통기한(`YYYY-MM-DD`) 입력 및 예외 처리
2. **D-Day 및 정렬 조회**: 오늘 날짜 기준으로 남은 유통기한을 계산하고 임박순으로 정렬
3. **레시피 자동 추천**: 현재 냉장고 재료 매칭률이 50% 이상인 레시피 및 부족한 재료 안내

## 🛠️ 개발 환경
- **Language**: Python 3.10+
- **Modules**: `datetime` (표준 라이브러리)

## 🚀 실행 방법

```bash
python main.py
```
